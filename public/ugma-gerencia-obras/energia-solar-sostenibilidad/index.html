2. Criterios Bioclimáticos de Guayana y Estándares Internacionales (ASHRAE / EDGE)

Puerto Ordaz y la región Guayana se caracterizan por una radiación solar privilegiada (\(HSP \approx 5.0 - 5.3 \text{ kWh/m}^2/\text{día}\)), pero acompañada de altas temperaturas diurnas y humedad relativa. En la gerencia de proyectos sostenibles, la adopción de normativas como ASHRAE 90.1 y sistemas de certificación EDGE Buildings (del Banco Mundial) exige priorizar estrategias pasivas:

  • Orientación Solar: Fachadas principales orientadas hacia el eje Norte-Sur para minimizar la ganancia solar directa en el este y oeste.
  • Protección Solar en Ventanería: Quiebrasoles, aleros paramétricos y vidrios de baja emisividad (Low-E) con SHGC < 0.35 para reducir el consumo del aire acondicionado hasta un 35%.
  • Inclinación Óptima de Paneles: Para la latitud de Puerto Ordaz (8.3°N), una inclinación mínima de 10° orientada al Sur favorece el autolavado por lluvia y maximiza la radiación incidente anual.

3. Script Python: Cálculo de Radiación Solar & Dimensionamiento Fotovoltaico

El siguiente algoritmo modela la producción fotovoltaica en función de las Horas Solar Pico (HSP) y el Performance Ratio (PR): 

def dimensionar_fotovoltaico(demanda_mensual_kwh, fraccion_solar, hsp=5.1, panel_wp=550, pr=0.78):
    demanda_diaria = (demanda_mensual_kwh / 30.0) * (fraccion_solar / 100.0)
    
    # Potencia pico requerida en kWp
    kwp = demanda_diaria / (hsp * pr)
    
    # Cantidad de módulos
    potencia_modulo_kw = panel_wp / 1000.0
    num_paneles = int(round(kwp / potencia_modulo_kw))
    potencia_real_kwp = num_paneles * potencia_modulo_kw
    
    # Generación anual (MWh/año)
    generacion_anual_mwh = (potencia_real_kwp * hsp * 365 * pr) / 1000.0
    
    # Mitigación de CO2 (Factor para red térmica: 0.50 kg CO2 / kWh)
    co2_ton_ano = (generacion_anual_mwh * 1000.0 * 0.50) / 1000.0
    
    return {
        "kWp": round(potencia_real_kwp, 1),
        "Paneles": num_paneles,
        "Generacion_MWh_ano": round(generacion_anual_mwh, 1),
        "CO2_Mitigado_Ton": round(co2_ton_ano, 1)
    }

resultado = dimensionar_fotovoltaico(6500, 60)
print(f"Sistema Solar: {resultado['kWp']} kWp | {resultado['Paneles']} Paneles | CO2 Evitado: {resultado['CO2_Mitigado_Ton']} Ton/año")
